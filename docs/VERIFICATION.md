## 자동 설치 패키지 검증 · 0.5.0

2026년 10월 11일, 같은 Apple M5 Max 36GB 맥에서 다음 범위를 확인했습니다.

- Python 자동 검사 **45개**, Swift 모델·워커 통합 검사, 오디오 **9개**, 내보내기 **12개**, 새 자동 설치 **8개**를 통과했습니다.
- 자동 설치 검사는 한글·공백 경로, 완료된 환경 재사용, 설치 실패 후 기존 환경 보존, 불완전한 환경 정리, 의존성 변경 후 새 환경 생성, 중복 설치 잠금, 실행 전·실행 중 취소와 관리 폴더 밖 경로 거절을 포함합니다.
- 사용자 데이터와 분리한 임시 폴더에 내장 uv로 **Python 3.12.15와 잠금 파일의 실제 AI 패키지를 새로 설치**했습니다. 주요 라이브러리 import 검사를 통과한 뒤에만 완료 포인터가 생성되는 것을 확인했습니다. 개발 프로젝트의 `.venv`를 복사하지 않았습니다.
- 새 Python 환경에서 합성 한국어 음성의 전사 → 요약 → EmbeddingGemma 2 검색·근거 답변을 실행했습니다. 전사 약 **5.29초**, 요약 약 **9.98초**, 검색·답변 약 **17.82초**였습니다. 짧은 합성 자료의 단일 관측값이며 성능 보장이나 실제 회의 정확도 평가는 아닙니다.
- 앱에 포함된 워커의 `install_models`로 기본 모델 준비를 완료했습니다. 이 검사는 기존 모델 캐시와 실행 중인 로컬 Ollama를 재사용했습니다. 모델을 전부 지운 새 맥에서의 최초 다운로드와 같은 검사는 아닙니다.
- 패키지에 포함된 Ollama **0.34.3**을 기존 서버와 다른 임시 포트에서 실행하고 버전 API 응답을 확인한 뒤 종료했습니다. 기존 서버 재사용·직접 시작한 서버만 정리·취소 시 정리는 모의 프로세스 검사에서도 확인했습니다.
- `.pkg`를 실제로 생성하고 내부 앱을 별도 폴더로 풀어 원본 파일과 바이트를 비교했습니다. 개발용 `runtime.json`이 포함되지 않으며 `/Applications/SoriNote.app` 설치와 재배치 금지가 설정되어 있습니다. 앱 코드 서명 검증도 통과했습니다.
- 새 설치 화면은 앱 자체 SwiftUI로 렌더링하여 확인했습니다. 실제 사용자 화면을 조작하거나 녹음 권한을 바꾸지는 않았습니다.

**다른 맥·새 계정에서 설치 프로그램을 끝까지 실행하는 검사, Developer ID 서명, Apple 공증과 Gatekeeper 배포 검사는 수행하지 않았습니다.** 현재 생성한 설치 패키지는 서명되지 않았으며 내부 앱에는 로컬 임시 서명을 사용합니다. 시스템의 응용 프로그램 폴더에 실제 설치하거나 기존 사용자 설정을 변경하지 않고 검증했습니다.

## 실제 모델 연결 검사

macOS의 Yuna 음성으로 다음 내용을 합성했습니다.

> 이번 프로젝트는 금요일까지 초안을 완성합니다. 민수는 검색 기능을 확인하고 지민은 문서를 작성합니다.

Whisper가 반환한 전사문은 다음과 같았습니다.

```text
[00:00] 미지정: 이번 프로젝트는 금요일까지 초안을 완성합니다.
[00:03] 미지정: 민수는 검색 기능을 확인하고 지민은 문서를 작성합니다.
```

이 전사문을 요약한 뒤 “초안을 언제까지 완성하나요? 누가 문서를 작성하나요?”라고 질문했습니다.

```text
초안은 금요일까지 완성할 예정입니다 [1]. 문서는 지민이 작성합니다 [1].
```

근거 목록이 실제로 선택한 테스트 기록의 문단을 가리키는지도 검사했습니다. 해당 실행에서 전사는 약 5.37초, 요약은 약 11.95초, 검색과 답변 생성은 약 13.78초였습니다. 이는 매우 짧은 합성 음성의 단일 실행 관측값이며, 한 시간 회의의 처리 속도나 평균 성능을 나타내지 않습니다. 임베딩은 이전 버전의 Ollama 300M 대신 새 기본값인 EmbeddingGemma 2 직접 실행을 사용했습니다.

EmbeddingGemma 2를 따로 검사한 결과도 다음과 같습니다.

| 항목 | 단일 실행 관측값 |
| --- | --- |
| 실행 장치 | Apple GPU · MPS |
| 라이브러리 | Sentence Transformers 6.1.0 / Transformers 5.19.0 / torchvision 0.29.1 |
| 출력 | 문서 2개와 질문 1개, 모두 768차원, float32 실행 |
| 관련 문서 유사도 | 0.7586 |
| 무관한 문서 유사도 | 0.5468 |
| 로드·3개 벡터 생성 시간 | 약 7.50초, Python 프로세스 시작 시간 제외 |

관련 문서는 “금요일까지 온보딩 문서 초안 완성”, 무관한 문서는 점심 메뉴, 질문은 문서 초안 마감일입니다. 작은 연결 검사이며 검색 정확도 벤치마크는 아닙니다. `HF_HUB_OFFLINE=1` 상태에서 캐시만 사용했습니다.

재실행 방법:

```bash
bash scripts/test.sh
.venv/bin/python scripts/smoke-models.py
.venv/bin/python scripts/smoke-embedding.py
python3 scripts/smoke-api.py
```

실제 모델 검사는 가중치와 Ollama가 준비된 상태에서 실행해야 합니다. API 검사는 로컬 모의 서버만 사용하며 외부 계정은 필요하지 않습니다. 검증용 파일과 결과는 `.runtime/`에 저장하며 Git에서는 제외합니다.

## 화자 분리 검증 범위

직접 실행 화자 분리 코드는 pyannote 4 API와 Community-1의 로컬 디렉터리 로딩 방식에 맞춰 구현했습니다. 라이브러리 import, 단어 시각과 화자 구간의 겹침 계산, 미확인 구간 처리, 화자 분리 실패 시 전사문 보존을 확인했습니다. 추가한 API 경로는 모의 서버가 제공한 화자 구간으로 정렬과 본문 보존을 검증했습니다. 실제 음성 화자 모델의 품질을 검증한 것은 아닙니다.

**Community-1 가중치로 실제 다화자 음성을 추론하는 검사는 수행하지 않았습니다.** 이용 조건에 동의한 사용자의 Hugging Face 토큰을 제공받지 않았기 때문입니다. 설정 화면에서 동의한 계정의 읽기 토큰을 입력하고 모델을 준비한 뒤 사용해야 합니다. 특정 화자 수와 한국어 회의의 분리 정확도를 검증했다고 주장하지 않습니다.

- 잠자기·전원 차단·디스크 부족 상황의 녹음 복구 품질
- 외부 OpenAI 호환 공급자의 실계정·실제 API Key 호출
